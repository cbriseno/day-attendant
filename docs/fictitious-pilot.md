# Synthetic pilot

Start `day-attendant web --synthetic --state PATH` with a new private directory.
The seeded responsibilities are fictional. Use this workspace to inspect the
connected interface and conversation without importing or migrating personal data.

Activation supports several simultaneous fronts. Snooze preserves due dates.
A concrete consequence is reviewed before the state change; the human may cancel,
correct context, retry or explicitly continue. Rest is legitimate and does not
create a task. Unavailable reasoning remains visible rather than implying approval.

Starting this workspace installs no scheduler or external inbox integration.
For optional scheduling and backup/recovery, see [daily operation](daily-operation.md).
For deployment checks on the managed Mac, see the [macOS handoff](macos-handoff.md).
