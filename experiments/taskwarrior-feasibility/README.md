# Taskwarrior feasibility experiment

Historical isolated Linux checks of Taskwarrior 3.5.0 before backend adoption.
The probe exercised native task identity, state, snooze, dependencies, recurrence
and concurrency using synthetic data. The JSON records preserve the original
observations and their language; they are evidence, not translated product copy.

`provenance.json` records source provenance; `installation-linux.json` describes
the development build. The ignored `.runtime` directory is not distributed.
These observations do not establish a corporate-approved macOS dependency chain.
